# AI Engineer Notes

## Role
An AI Engineer builds, integrates, and deploys AI/ML models into real applications.

## Core Skills
- Python, NumPy, Pandas
- Machine Learning basics (regression, classification, clustering)
- Deep Learning (neural networks, CNN, RNN, Transformers)
- LLMs and prompt engineering
- Frameworks: PyTorch, TensorFlow, scikit-learn, Hugging Face

## Key Concepts
- **Training vs Inference**: training teaches the model, inference uses it.
- **Overfitting**: model memorizes training data and fails on new data.
- **RAG (Retrieval-Augmented Generation)**: LLM answers using retrieved documents.
- **Embeddings**: numeric vectors that represent meaning of text.
- **Fine-tuning**: adapting a pre-trained model to a specific task.

## Typical Workflow
1. Define the problem
2. Collect and clean data
3. Train and evaluate the model
4. Deploy as an API
5. Monitor and improve

## Tools
Jupyter, Docker, FastAPI, vector databases (Pinecone, FAISS), MLflow
