# UI/UX Engineer Notes

## Role
A UI/UX Engineer designs how a product looks (UI) and how it feels to use (UX), and often builds it in code.

## UI vs UX
- **UI (User Interface)**: visual design - colors, typography, buttons, layout, icons
- **UX (User Experience)**: overall experience - ease of use, flow, usability, user satisfaction

## UX Design Process
1. **Research**: user interviews, surveys, competitor analysis
2. **Define**: user personas, user journeys, problem statement
3. **Ideate**: sketches, user flows, information architecture
4. **Prototype**: wireframes, then high-fidelity mockups
5. **Test**: usability testing, gather feedback
6. **Iterate**: improve based on results

## Core Design Principles
- **Consistency**: same patterns across the product
- **Hierarchy**: guide the eye to what matters most
- **Contrast and readability**
- **Whitespace**: give content room to breathe
- **Feedback**: show users that actions worked (loading, success, error)
- **Accessibility**: usable by everyone (WCAG, alt text, keyboard navigation)

## Key Concepts
- **Wireframe**: low-detail layout sketch
- **Prototype**: clickable model of the product
- **Design System**: reusable components, colors, fonts, rules
- **Responsive Design**: works on mobile, tablet, desktop
- **Mobile-first**: design for small screens first

## Front-end Skills (UI Engineer)
