# DevOps Notes

## What is DevOps?
A culture and set of practices that bring Development and Operations together to deliver software faster and more reliably.

## Core Practices
- **CI (Continuous Integration)**: automatically build and test on every commit
- **CD (Continuous Delivery/Deployment)**: automatically release to environments
- **Infrastructure as Code (IaC)**: manage servers with code (Terraform, Ansible)
- **Monitoring and Logging**: Prometheus, Grafana, ELK stack

## Key Tools
| Area | Tools |
|------|-------|
| Version control | Git, GitHub |
| CI/CD | GitHub Actions, Jenkins, GitLab CI |
| Containers | Docker |
| Orchestration | Kubernetes |
| Cloud | AWS, Azure, GCP |

## Docker Basics
- **Image**: blueprint of an app
- **Container**: running instance of an image
- `docker build`, `docker run`, `docker ps`

## DevOps Lifecycle
Plan -> Code -> Build -> Test -> Release -> Deploy -> Operate -> Monitor
