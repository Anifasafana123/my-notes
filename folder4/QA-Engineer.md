# QA Engineer Notes

## Role
A QA Engineer makes sure software works correctly and meets requirements before release.

## Types of Testing
- **Unit testing**: tests small pieces of code
- **Integration testing**: tests modules working together
- **System testing**: tests the full application
- **Regression testing**: checks old features still work after changes
- **Smoke / Sanity testing**: quick checks of main features
- **Performance testing**: speed and load
- **UAT**: User Acceptance Testing by the end user

## Manual vs Automation
- Manual: human executes test cases, good for exploratory and UI checks
- Automation: scripts run tests, good for repeated regression tests

## Test Artifacts
Test plan, test cases, bug reports, traceability matrix

## Bug Life Cycle
New -> Assigned -> Open -> Fixed -> Retest -> Verified -> Closed (or Reopened)

## Tools
Selenium, Playwright, Cypress, Postman, JMeter, JUnit, pytest, Jira

## Good Bug Report Includes
Title, steps to reproduce, expected vs actual result, severity, screenshots
